An automated security posture discovery, compliance auditing, and reporting engine designed for multi-cloud enterprise architectures across **Google Cloud (GCP)**, **AWS**, **Azure**, and **OCI**.

---

## Capabilities

- **Automated Security Discovery**: Continuous inventory and policy compliance verification.
- **Detailed Security Reports**: Domain-by-domain compliance analysis and remediation recommendations.
- **CIS Benchmark Alignment**: Mapped to CIS Foundation Benchmarks and NIST frameworks.
- **Cloud Run Job Automation**: Automated scheduled discovery executions with BigQuery archiving.
